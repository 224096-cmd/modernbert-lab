🧭 情報たしかめラボ

Web 情報の信頼性を、手順で検証する

SNS・ニュース・動画で見た情報について、検証対象を明示し、公開情報を集めて照合し、根拠を示して判定するというファクトチェックの手順を、ブラウザだけで実行できます。収集した記事と主張の照合は端末内の日本語言語モデルが行い、判定の下書きと根拠つきの検証記録を出力します。最終的な判定は利用者が根拠を読んで行います。

1検証対象を明示する「誰が・何を・いつ」が入った、客観的に確かめられる一文にする。意見や予測は対象外
2公開情報を集める検索演算子（site:go.jp など）で一次情報・報道・検証記事を探す。画像は逆画像検索
3照合する集めた記事が主張と一致するか・矛盾するか、発信元の種類と日付とともに読む
4判定し、過程を記録する5 段階で判定し、検索式・出典 URL・理由を残す。誰でも同じ手順で再現できるように
利用にあたって
  • 登録・ログインは不要。入力内容と結果はこの端末（ブラウザ）にだけ保存され、外部には送られません。右上の 🔒 で「保存しない」にも切り替えられます
  • 初回のみ判定用モデル（約 110 MB）をダウンロードします。2 回目以降はオフラインでも照合できます
  • コンピュータの判定は下書きです。根拠のリンクを開き、一次情報を確認してから判定してください。人物の特定や非公開情報の取得には使えません

ファクトチェックの手順を、端末内の ModernBERT で支援する

検証対象を明示 → 検証過程を公開 → 判定というファクトチェックの基本手順（日本ファクトチェックセンターの講座に準拠）に沿って、主張を入れるとブラウザが高度な検索で公開情報を集め、端末内の日本語 ModernBERT（最大 8,192 トークンを分割せずに読む）で主張と各記事の含意・矛盾を照合し、5 段階の判定の下書きと根拠リンクつきの検証記事を作る。画像・動画の逆検索、公開データ、ジオロケーションなどの外部ツールもここから開ける。LLM を使わず、サーバも API キーも不要。

初めて使う方へ

  • アカウント登録・ログインは不要。入力した内容と結果はあなたの端末（ブラウザ）だけに保存され、作者を含め誰にも送られない
  • 初回はモデル（約 110 MB）を端末にダウンロードする。2 回目からはオフラインでも判定できる。Wi-Fi での初回利用を推奨
  • 検索・本文取得は無料の公開経路を使うため、混雑時は遅くなることがある。結果は届いた順に表示される
  • 機械の判定は下書き。必ず根拠リンクを開いて一次情報を確かめる。人物の特定や非公開情報の取得には使えない
  • 履歴を残したくないときは右上の「🔒」でプライベートモードに。結果はタブを閉じると消える
  • 別の端末に履歴を移すには「設定」→ JSON で書き出し → もう一方で読み込む

トピック／URL→Dorks で検索エンジン巡回→本文抽出→信頼性採点（出所・内容・裏取り・時間）→コーパスとして履歴に保存→検証／ギャップ／構造化（埋め込み・含意・リランカー）

各機能で何をしているか

矛盾・整合各記事の要旨（冒頭の命題）を他記事の段落と突き合わせ、含意モデルで 一致／矛盾／無関係 を判定して行列にする 偏り・客観性埋め込みゼロショット（客観／主観／感情／宣伝）＋ 含意ゼロショット（「この文章は客観的な事実を報告している」など）＋ 語彙（煽り語・推量表現・宣伝語の密度）を合成し 0〜100 一次情報出所の種別（公的・報道・ブログ…）＋ 引用・伝聞表現と発表元表現の数 ＋ 含意ゼロショット（一次／二次） 時間的矛盾年月・和暦・数値＋単位を抽出。本文中の最新年が古いのに「現在」と書く／公開日より新しい年／同じ項目で記事間の数値が食い違う、を警告 ナレッジギャップ12 種類の問いテンプレートをトピックに当て、埋め込みで候補段落を絞り、リランカーの関連度がしきい値未満なら「未回答」。未回答の問いには検索式を提案 対立視点段落を 賛成／反対／中立 にゼロショット分類し、反対・課題の段落を列挙。加えて記事間の命題ペアで含意モデルが「矛盾」としたものを列挙 意味差分文を埋め込みで対応づけ、変わった対を含意モデルで双方向に判定：両方向含意＝言い換え、片方向＝情報の増減、矛盾＝意味の反転 比較表軸ごとに「軸は何か」を問いとして各記事の文をリランカーで採点し、最良の文をセルに入れる 要約段落の埋め込みの重心との類似（出所の重みつき）を関連度とし、MMR で冗長を避けて選ぶ。抽出型なので出典が必ずつく Q&A埋め込みで候補 → リランカーで関連度 → 上位段落を根拠として提示。質問が命題なら含意も判定

信頼性スコア R（0–100）

R = 100 × ( wsrc·ssrc + wcon·scon + wcor·scor + wtime·stime )

ssrc 出所ドメイン種別の基礎点（公的 1.0 … SNS 0.3）＋ HTTPS ＋ ドメイン年齢（Wayback 最古）＋ Wikipedia 出典回数 ＋ 著者・日付scon 内容0.35·長さ ＋ 0.40·具体性（数値・日付・引用・固有名詞）＋ 0.25 ＋ 文体（煽り −0.3、報告 +0.2、意見 −0.1、宣伝 −0.2）scor 裏取り要旨を他ドメインの段落が含意する重み付き件数 S（同趣旨の中立は部分点）、矛盾 C：0.15 + 0.85·(1−e−S/2) − 0.6·(1−e−C/2)stime 時間0.2 + 0.8·0.5経過日数/30（日付なし 0.4）

プライベートモード

残らないもの：集めた記事・採点・検証結果・検証記事の下書き・ドメイン情報のキャッシュ。残るもの：ダウンロードしたモデル（誰の情報でもない）と設定値。外部ツールへのリンクを開いた先（Google など）の記録はこのアプリの範囲外。再調査の差分や推移グラフは履歴が前提なので、このモードでは使えない。

履歴

別の端末で同じ履歴を見たいときは、書き出した JSON を（クラウドドライブなどで）移して読み込む。サーバやアカウントは使わない。
